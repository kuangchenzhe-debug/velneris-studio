PROTOTYPE DISCLOSURE

Privacy information

Last updated: October 8, 2026. Velneris Studio is an early-stage prototype. This page describes the behavior of this reference implementation, not a production-ready privacy policy.

What this prototype stores

Creative briefs, shot lists and prompts can be saved in your own browser using localStorage when you click “Save locally.” The demo server does not intentionally store your input bodies, uploaded images, or generated projects in a database.

External AI processing

Only when you explicitly select and authorize Claude API mode will the content you submit be sent to Anthropic for processing. When you explicitly request frame analysis, the selected image is sent to Anthropic for that request. Review Anthropic's relevant privacy policies before enabling the live integration.

Public deployment

Hosting providers and reverse proxies may retain access logs. Before collecting real user data, the project owner must publish an accurate policy naming the actual operator, describing retention, security, lawful processing basis, user rights and a working contact address. Do not rely on this prototype statement as final legal documentation.
